# Справочник

## Класс `Templator`

`KolodochkaDev\Lathe\Templator`

Основной класс для рендеринга скомпилированных шаблонов.
Использует трейт HasTemplator.

### Методы

#### Конструктор

```php
__construct(string $compilePath, string $sourcePath)
```

Создаёт экземпляр шаблонизатора.

*Параметры:*
- **`compilePath`** — путь к директории со скомпилированными шаблонами.
- **`sourcePath`** — путь к директории с исходными шаблонами.

#### Создание шаблона

```php
view(string $path, array $data = []): string
```

Рендерит скомпилированный шаблон и возвращает результат.

*Параметры:*
- **`path`** — путь к шаблону относительно $sourcePath.
- **`data`** — ассоциативный массив данных для шаблона.

*Результат:* строка.

*Исключения:* Exception, если шаблон не скомпилирован.

## Класс `Compiler`

`KolodochkaDev\Lathe\Compiler`

Класс для компиляции исходных шаблонов в PHP-код.

### Методы 

#### Конструктор

```php
__construct(string $compilePath, string $sourcePath)
```

Создаёт экземпляр компилятора.

*Параметры:*
- **`compilePath`** — путь к директории для скомпилированных шаблонов.
- **`sourcePath`** — путь к директории с исходными шаблонами.

#### Компиляция

```php
compileDir(): void
```

Рекурсивно компилирует все .html файлы из **$sourcePath**.

## Класс `StringTemplator`

`KolodochkaDev\Lathe\StringTemplator`

Класс для шаблонизации строк без компиляции. Использует трейт HasTemplator.

## Трейт HasTemplator

`KolodochkaDev\Lathe\Traits\HasTemplator`

Предоставляет методы шаблонизации для использования внутри классов.

### Методы 

#### Цикл

```php
loop(iterable $in, ?Closure $callback = null): string
```

Перебирает iterable и применяет обратный вызов к каждому элементу.

*Параметры:*
- **`in`** — массив, iterable
- **`callback`** — замыкание fn($value, $key): string

*Результат:* объединённая строка.


#### Условие

```php
if(mixed $flag, string|Closure $template, string|Closure|null $elseTemplate = null): string
```
Условный вывод.

*Параметры:*
- **`flag`** — условие
- **`template`** — значение или замыкание для истинного условия
- **`elseTemplate`** — значение или замыкание для ложного условия (опционально)

*Результат:* строка.


#### Вывод

```php
pl(string|Closure $template): string
```
Выводит значение или результат замыкания.

*Параметры:*
- **``template``** — строка или замыкание.

*Результат:* строка.


#### Объединение

```php
mr(...$vals): string
```
Объединяет переданные значения в одну строку.

*Параметры:*
- **`...vals`** — значения для объединения.

*Результат:* строка.


#### Количество элементов массива

```php
count(array|Countable $input): int
```
Возвращает количество элементов.

*Параметры:*
- **`input`** — массив или объект, реализующий Countable.

*Результат:* целое число.
