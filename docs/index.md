# Начало работы

## Требования

PHP 8.1 или выше.

## Установка
Шаблонизатор Lathe может быть установлен как PHP пакет командой:
```bash
composer require kolodochka-dev/lathe
```

## Первый шаблон
Lathe работает с двумя типами файлов:
- **Исходные** шаблоны — это .html файлы, с которыми вы работаете непосредственно, используя синтаксис Lathe.
- **Скомпилированные** шаблоны — это .php файлы, которые создаются автоматически и используются для рендеринга.

Чтобы использовать Lathe необходимо создать папку в которой будут располагаться все ваши **исходные** шаблоны. Для примера расположим шаблон по пути 
"{корень проекта}/templates/example.html" c содержимым:
```html
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>{$if(isset($title), $title, 'Default Title')}</title>
</head>
<body>
    <h1>{$body}</h1>
</body>
</html>
```

Все управляющие конструкции Lathe такие как `$if(isset($title), $title, 'Default Title')` являются переменными которые содержат анонимные функции возвращающие результат в виде строки.
В случае $if это функция которая принимает логическое условие и возвращаемые значения для истинного и ложного (не обязательный параметр) условия. Также значения 
могут быть переданны в виде замыканий `$if(isset($title), fn () => $title, fn () => 'Default Title')`

## Компиляция
Для компиляции шаблонов используется команда `php ./vendor/bin/lathe-compile ./templates ./compiled` которая принимает два аргумента:
1. Путь к **исходным** шаблонам
2. Путь по которому будут храниться **скомпилированные** файлы (должна быть создана и доступна для записи)

## Вывод шаблона
После выполнения компиляции шаблон может быть получен функцией view класса `KolodochkaDev\Lathe\Templator`, конструктор которого принимает абсолютные пути 
к директориям **скомпилированных** и **исходных** файлов. Сама функция принимает путь к шаблону относительно директории **исходных** файлов и необходимые для вывода данные.

```php
use KolodochkaDev\Lathe\Templator;

$templator = new Templator(__DIR__ . '/compiled', __DIR__ . '/templates');
echo $templator->view('example.html', [
    'title' => 'Title',
    'body' => 'Body',
]);
```
